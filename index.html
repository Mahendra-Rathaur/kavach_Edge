Form and email integration (needs configuration)

The form validates in the browser, then opens the visitor's email app with the enquiry pre-filled, addressed to the email in CONFIG.email. Nothing is stored or sent by a server. For direct delivery, deploy the site to your own host and connect a form service (for example Formspree, Netlify Forms or an AWS SES function) by posting to its endpoint. Keep API keys on the server side, never in this file.

Editing content

Brand name, email, LinkedIn and per-technology status (available, in-progress, partner) are in the CONFIG and TECH objects at the bottom of this file. Yellow placeholders in About and the capability statement must be replaced with verified facts.

Deployment

This is a single static HTML file. Host it on Cloudflare Pages, Netlify, Vercel or any static host, attach your domain, enable HTTPS, then add a real og:image and canonical URL. For a framework build (Next.js or Astro), each section maps to one component.
